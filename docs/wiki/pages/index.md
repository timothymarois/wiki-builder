**wiki-builder** turns markdown pages into a wiki like this one, and then refuses the things that make
documentation stop being true. Every page here was written with it and passes its checks, so this wiki is
both a description of the tool and a demonstration of it.

The [brief](brief.md) says in one screen what the tool is, who it is for and what it refuses.

A person writes [pages](pages.md), and an agent learns to write them from the [skill](skill.md). The
build makes the [site](site.md), and the [local server](serving.md) shows it on this machine. The
[checks](checks.md) are the reason the tool exists, and the [commands](commands.md) show how to
use it.

The [goals page](goals.md) collects what every part of the tool is for.
